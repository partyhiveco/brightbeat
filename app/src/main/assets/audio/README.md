The bundled setlist references royalty-free/original files `demo1.mp3` through
`demo8.mp3`, matching the `audioFile` field in `assets/charts/demo1.json` …
`demo8.json`.

No copyrighted audio is bundled with this project — see the copyright
discussion in chat for why. Good sources for a placeholder track:
- Free Music Archive (freemusicarchive.org) - filter by CC0 / public domain
- incompetech.com (Kevin MacLeod, CC-BY)
- Your own original composition

`demo1.json` contains a hand-authored pattern. The other demo charts start
with metadata and use deterministic BPM-grid auto-mapping through each track;
replace those generated notes with authored timings when polishing a song.
The in-app chart editor (future step) is meant to make that easy by letting
you scrub the track and tap out notes live.
